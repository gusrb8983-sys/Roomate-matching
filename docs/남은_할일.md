# 남은 할 일 (순서대로)

최종 제출: 2026-11-22 (보고서 PDF, 프로그램 파일, 시연 영상 3~4분)

## 완료

1. 데이터 최종본: 입주 시기, 동 이름 통일(명륜1가 형식), 닉네임·연락 링크, 정답 사례 4쌍
2. 관심 등록·매칭 요청 저장 파일 형식 (`data/interests.csv`, `data/requests.csv`)
3. 데이터 읽기·저장 함수 (`src/data_io.py`)
4. 매칭 기본 함수: 제외 조건, 일치율, 매물 출발 추천 (`src/matching.py`)
5. 데이터 정합성 점검과 수정, 문제 기록 (`docs/겪은문제_기록.md`)

## 남은 일

6. 룸메이트에서 출발하는 추천: 희망 지역·예산 겹침 판정, 상위 5명, 두 사람의 공통 매물 찾기
7. 매칭 요청 처리: 요청 가능 여부 검사(제외 조건, 중복), 수락 시 링크 공개, 거절 시 같은 매물 재요청 막기, 72시간 만료
8. 정답 사례 검증 결과표: 4쌍 실행 결과 정리
9. Streamlit 화면
   - 9-1. 시작: 닉네임으로 기존 사용자 선택 또는 새 프로필 만들기
   - 9-2. 프로필 입력 (체험자 데이터는 별도 저장, GitHub 제외)
   - 9-3. 추천 룸메이트 카드 (일치율, 항목별 비교, 공통 매물, 매칭 요청 버튼)
   - 9-4. 매물 목록·상세, 관심 등록, 그 매물의 추천 룸메이트
   - 9-5. 요청함 (받은·보낸 요청, 수락·거절, 수락 시 링크 표시)
10. 휴대폰 화면 점검과 오류 수정
11. 실행 점검: `requirements.txt`, 실행 방법 문서, 다른 컴퓨터에서 실행 확인
12. 배포: Streamlit Cloud, 휴대폰 접속 링크
13. 만족도 평가: 설문 폼 생성, 지인 5~10명 체험(닉네임·예시 링크 사용 안내), 설문 집계
14. 보고서 재료 정리: 화면 캡처, 최종 순서도·의사코드, 수업 내용 반영표, 문제 기록 갱신, AI 사용 내역
15. 최종 보고서 작성, 시연 영상 촬영, 최종 제출
